# InvoicePro

A PHP-based Billing and Invoice Management System designed to help businesses create and manage invoices efficiently.

## About the Project

InvoicePro is a web-based billing and invoice management system developed using PHP.

The system provides a simple interface for managing products, creating bills and invoices, viewing billing history, and managing user profiles.

## Features

- User Sign Up
- User Login
- Dashboard
- Product Management
- Create Bill
- Create Invoice
- Invoice History
- Bill History
- User Profile
- Logout

## Technologies Used

- PHP
- HTML
- CSS
- JavaScript
- MySQL
